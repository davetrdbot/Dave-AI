# Project skills

`apple-design` and its eight sibling skills are the Apple HIG / Liquid Glass design family
(s1gmamale1/apple-design-skills), vendored here so the design language of the admin panel and the
mobile app is a checked-in reference rather than something re-derived from memory each session.

Start at `apple-design/SKILL.md` — it is the hub and routes to the rest. The two that matter most
for this repo:

- `apple-design-materials` — the glass recipes (and the limits: CSS cannot do real lensing),
  the app-icon squircle, and SF Symbols.
- `apple-design-foundations` — layout, spacing, typography, semantic color.

Two rules from the hub worth repeating here, because both cut against the obvious instinct:

- **Glass is chrome only** — nav, sheets, sidebars. Not every card. Never glass on glass.
- **Light is the default, dark is the exception.** Do not default to a dark dashboard.
